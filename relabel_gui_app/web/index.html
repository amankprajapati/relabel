Run trackerByteTrack, running locally

Links the boxes already in this project across frames so each object gets one track id. Each track's class becomes the majority class of its boxes. Boxes are never moved, and the whole run is one Ctrl+Z.

Scores are read from a score or confidence attribute on each box. Boxes without one count as fully confident.

How to use Relabel

Workflow

  1. Open a VIA JSON and its frames folder.
  2. No track ids yet? Track links the boxes across frames.
  3. Click an object in the list or on the image and press 1-9, or click its class label. The class changes on every frame of that track.
  4. Fix ids: select an object and Merge it into the right id.
  5. Edits save automatically to *.edited.json. The original is never written.

Editing boxes

  • Drag on an empty part of the image to draw a box of the New box class. Ctrl+drag draws on top of another box.
  • Click a box to select it. Drag it to move, or drag a corner to resize.
  • Double-click to reach a box hidden behind another.
  • Missing on some frames? Ctrl+C the box, go to the frame, Ctrl+V. It keeps its track id.
